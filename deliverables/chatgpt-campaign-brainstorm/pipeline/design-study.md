# Design Study — Reference DNA

## Reference intent: READY

Reference image: "How Claude and I run every channel" (Charlie Hills)

## Extracted structural mechanisms

| Mechanism | Reference | Applied in this post |
|---|---|---|
| editorial-workflow-map | multi-row horizontal pipeline per channel | 3-column layout: intake → hub → stages |
| left-side intake | vertical IDEAS → HERMES → BRIEF | 4-block sequential input column |
| one dominant operator hub | orange OPERATOR HUB with Claude icon | navy ChatGPT hub with accent ring pulse |
| connected horizontal stages | MAKE → BUILD → RUNS → PUBLISH per row | UNDERSTAND → EXPAND → BUILD → CHALLENGE → NARROW |
| thin directional connectors | arrows connecting each stage cell | SVG path connectors with animated draw-on |
| restrained warm accent | coral/orange #B8471B-area | coral/orange #D95F2B |
| subtle background grid | light dot/line grid texture | radial-dot grid at 4-5% opacity |
| compact stage labels | small uppercase labels above each stage | stage-label 8px 800 weight .18em spacing |
| feedback loop closure | "the data picks the next idea" Apify row | dashed curved SVG arc: bottom → input area |

## Structural differences (originality decisions)

- Reference uses rows × channels; this post uses ONE left-right workflow path
- Reference has 4 columns per row; this has 5 sequential stages in vertical cards
- Reference operator hub is centered/left; this hub is center-column anchor
- Reference uses full-color brand logos; this uses text label only (verified-identity policy)
- Reference has a "base layer" Notion zone; this has a takeaway strip + feedback signal box
- Palette family similar (coral orange) but shifted warmer toward burnt orange; background is warm off-white, not pure white
- Reference has a travel puck animation; this uses connector draw-on + node pulse instead

## Research gates applied

- structural-originality: PASS — layout archetype differs; not a palette-only reskin
- reference-dna: PASS — mechanism IDs extracted, no pixel-clone
- design-dials: visual-density=high, motion-intensity=moderate, structural-variance=high
- verified-identity-assets: ChatGPT text label only — no logo drawn, approximated, or generated
- intentional-typography: system-sans + system-mono — no remote font dependency
- contrast-discipline: navy #1E2A3A on white card well above 4.5:1; accent on white >3:1 for large copy
