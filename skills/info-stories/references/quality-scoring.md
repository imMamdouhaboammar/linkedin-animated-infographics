# Visual quality scoring

Score each applicable axis from 1–5 and attach both concrete evidence (`artifact`, selector/region, or frame) and one actionable finding. The established six axes are: Purpose, Hierarchy, Execution, Specificity, Restraint, and Variety. Any applicable score below 3 is blocking; the report verdict is `HOLD` until corrected. Non-applicable axes must say why and are not silently scored.

Reference decisions are explicit: `HOLD` when required reference evidence is missing/invalid; `SKIP` when no reference was supplied. Originality evidence must name the selected study IDs/capsules and the local transformation, never claim similarity as proof.
