## Public ZIP boundary

The Codex/ChatGPT release ZIP is allowlist-driven. It includes the OpenAI plugin manifest, the complete `openai-skills/` runtime, plugin assets, and public legal/support documents.

`demos/` and all demo media are intentionally excluded from the ZIP. Tests, CI configuration, canonical Claude/Antigravity worker internals, helper/research internals, and transient local artifacts are excluded as well.

The repository may continue to keep demo media for project/reference purposes; those assets are not part of the public Codex/ChatGPT package.
