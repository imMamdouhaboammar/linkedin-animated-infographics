## Identity rules

Named identity assets are resolved before creative production. Exact user-supplied official files take precedence, followed by inspectable original-owner assets. Platform/tool logos may use a pinned Vibe SVGs mirror when exact provenance is recorded, then verified Lobe assets may be used when appropriate. Ambiguous identity returns HOLD instead of producing a lookalike.

Vibe SVGs mascot and scene artwork marked `communityArtwork: true` remains community/fan-made artwork. It must not be called official and cannot satisfy an official/original mascot requirement without an independently verified official source.

Approved identity assets are identity-locked. Geometry, identity colors, wordmarks, aspect ratio, and mascot-defining features cannot drift downstream without reopening asset resolution.

## Narrative and demos

Repository `demos/` is treated as a taste corpus when a checkout exposes it. The workflow selects only a bounded number of relevant examples and extracts transferable narrative rules rather than copying wording, logos, mascot geometry, exact palette measurements, distinctive layouts, or frame-by-frame sequences.

The installed ChatGPT/Codex package does not pretend repository demo media is locally available. Its narrative guidance is self-contained.

## Sister Plugins

Six Sister Plugin URLs are carried as optional companion references. Their names, capabilities, installation state, permissions, and successful invocation are never inferred from the URLs. Core infographic production does not depend on them.

## Public ZIP boundary

The Codex/ChatGPT release ZIP is allowlist-driven. It includes the OpenAI plugin manifest, the complete `openai-skills/` runtime, plugin assets, and public legal/support documents.

`demos/` and all demo media are intentionally excluded from the ZIP. Tests, CI configuration, canonical Claude/Antigravity worker internals, helper/research internals, repository-only scripts, and transient local artifacts are excluded as well.

The repository may continue to keep demo media and repo-only retrieval helpers for project/reference work; those assets and helpers are not public Codex/ChatGPT runtime dependencies.
