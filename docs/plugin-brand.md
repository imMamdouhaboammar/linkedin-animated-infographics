# ChatGPT/Codex Plugin Brand Kit

## Core idea

The mark combines a three-step infographic bar rhythm with a play indicator. The bars represent structured visual information; the play shape represents that information becoming motion. The identity describes the product job directly instead of using generic AI imagery.

## Geometry

All variants use the same three descending rounded bars and the same forward play wedge inside a square 512x512 viewBox. The compact icon adds a rounded square field so the mark remains legible at small Plugin Directory and composer sizes.

## Palette

- neutral dark: `#111111` / `#151515`
- warm light: `#F5F1E8`
- motion accent: `#FF6B4A` on dark surfaces and `#E9553C` on light surfaces

The accent is reserved for the play/motion cue. The bars carry the infographic structure.

## Assets

- `assets/logo-light.svg`: transparent light-surface variant with dark bars
- `assets/logo-dark.svg`: transparent dark-surface variant with warm-light bars
- `assets/plugin-icon.svg`: compact square icon used by the manifest for `logo` and `composerIcon`

## Small-size behavior

The icon avoids text, gradients, filters, fine strokes, and remote resources. At small size the three-bar rhythm remains distinguishable and the accent play wedge provides the motion cue. Light and dark variants share the same core geometry.
