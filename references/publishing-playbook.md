# Publishing Playbook

## Upload

Upload the GIF as an **image**, not a document and not a video.

- LinkedIn autoplays GIFs uploaded through the image attachment path
- The document path turns it into a static PDF page
- The video path re-encodes it and adds a play button

If the GIF does not animate after posting, it was almost certainly attached the wrong
way, or it exceeded the size where LinkedIn transcodes. Delete and repost rather than
editing; editing a post after publishing suppresses its distribution.

## Links

Put every link in the **first comment**, posted immediately after the post goes live.
Then say so in the caption:

```
Full guide in the comments 👇
```

A link in the caption body reduces reach. This is consistent enough across the
reference set that all of them do it, including the ones whose entire purpose is
driving to a newsletter.

The exception is a bare domain written as plain text without `https://`, like
`how-to-ai.guide` or `bdos.ai`. Several reference posts use this and it appears to
avoid the penalty because LinkedIn does not render it as a link preview. It also means
the reader has to type it, which filters for intent.

## Comment gates

```
Comment "PLAYBOOK" and I'll send it to you for free.
(Must be connected)
```

The `(Must be connected)` line matters. LinkedIn only allows DMs to first-degree
connections, so without it you collect comments you cannot fulfil, and the commenters
feel ignored.

The three-condition version grows followers as well:

```
→ Add me to your network
→ Follow BrandName
→ Comment "API"

I'll send it in a DM 🫡
```

Fulfil within 24 hours or the mechanic stops working — people talk.

**Keyword rules:** one word, all caps, 4–9 letters, semantically tied to the asset.
`PLAYBOOK`, `CREATIVES`, `GTM`, `API`, `CLAUDE`. Avoid words that appear naturally in
comments, or your filter catches noise.

## Repost mechanic

```
♻️ Repost this so they stop paying for websites they could build by lunch.
```

Name the benefit to a third party. `♻️ Repost if you found this useful` performs
noticeably worse than a line that tells the reader who to help and why.

## Timing

The reference accounts post on weekday mornings in their audience's time zone.
For an audience spanning Egypt, Saudi, and the UAE, 8–10am Riyadh time covers all three.
For a mixed Gulf and European audience, 9–10am CET.

Bilingual posts go 48 hours apart, not the same day. Posting both versions together
splits the engagement of a single audience across two posts.

## The first hour

Everything the reference accounts do in the first hour:

1. Post the first comment with the link, immediately
2. Reply to every comment within the first hour, with a real sentence rather than
   an emoji
3. Do not edit the post
4. Do not post again for at least 18 hours

## Reusing the artboard

One artboard supports more than one post:

- **The still** as a separate post 3–4 weeks later with a different caption archetype
- **A crop** of one panel as a standalone post
- **The same layout, new content** as a series. The reference accounts run recognisable
  visual series, and the recognition is a large part of why the format compounds
- **A carousel** built from the panels, for the audiences that still save carousels

## Measuring

Track four numbers per post:

| Metric | What it tells you |
|---|---|
| Impressions | whether the hook survived the truncation cut |
| Reactions ÷ impressions | whether the content matched the promise |
| Comments ÷ impressions | whether the CTA worked |
| Saves and reposts | whether the artboard is genuinely reference-grade |

Save rate is the one that matters for this format. A post with high impressions and low
saves means the visual looked good in feed but was not worth keeping, which means the
artboard had style and no information.
